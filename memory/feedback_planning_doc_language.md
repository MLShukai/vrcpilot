plan mode で `/home/gop/.claude/plans/*.md` 等に書く計画ファイル、および設計提案・仕様提示のための user-facing なドキュメントは日本語で書く。

**Why:** ユーザーが日本語話者で、計画レビュー・意思決定の対話は日本語前提。英語で出すと書き直しを要求される（実例: 2026-05-03 の capture API 改良計画で英語版を出して `日本語で計画ファイルを提示してください` と差し戻し）。

**How to apply:**

- plan mode で plan ファイルを書くときは最初から日本語で書き始める。code block 内のコード片・識別子・コマンド・パスは英語のまま（変えると意味が壊れる）
- AskUserQuestion の質問文・選択肢ラベルも日本語
- 一方で以下は英語のまま:
  - ソースコードの識別子・型注釈・docstring の構造（既存方針に従う）
  - コミットメッセージ（`<種別>(<scope>): <内容>` の `<内容>` 部は CLAUDE.md の例示に従い日本語可だが、英語でも許容されている既存スタイルを尊重する）
  - 英語で書くべき stderr 出力やエラー文言（`vrcpilot: ...` 等、ユーザー向けでも CLI の規約に従う）
- 迷ったら本文（説明・背景・判断根拠）は日本語、コード/コマンド/識別子は英語、と切り分ける
